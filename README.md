# Tricycle Ride Booking API

## Project Description

A REST API developed using Python Flask
that allows passengers to create, retrieve,
update, and cancel tricycle ride bookings.

## Technologies Used
- Python
- Flask
- Requests
- JSON
- GitHub

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | /api/rides | Get all rides |
| GET | /api/rides/{id} | Get one ride |
| POST | /api/rides | Create booking |
| PUT | /api/rides/{id} | Update booking |
| DELETE | /api/rides/{id} | Cancel booking |

## Installation

Install dependencies:

python -m pip install -r requirements.txt

## Run the Provider

python app.py

## Run the Consumer

python consumer.py

## Base URL

http://127.0.0.1:5000
